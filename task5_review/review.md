# Аналитический обзор кейс-задачи № 2 (Счётчик)

## Функциональность
Все требования выполнены: две кнопки, отображение результата,
смена фона (жёлтый/зелёный/красный), блокировка кнопок на ±10,
сообщение об экстремальном значении.

## Производительность
Приложение чисто клиентское, работает мгновенно.
Операции O(1), нет сетевых запросов.

## Удобство использования
Крупные кнопки, контрастный фон, наглядная цветовая индикация.
Можно улучшить: подписи «+»/«−» заменить на иконки, добавить hover-эффекты.

## Безопасность
Нет ввода пользователя — уязвимостей нет.
При переносе на сервер потребуется валидация и CSRF.

## Масштабируемость
Легко добавить шаг счётчика, кнопку сброса, сохранение в localStorage.

## Сопровождаемость
Код короткий, функции разделены. Можно вынести стили в отдельный CSS.

## Переносимость
Работает в любом современном браузере, зависимостей нет.

## Качество кода
Читаемые имена, единый стиль. Можно добавить JSDoc-комментарии.

## Тестирование
Ручное тестирование сценариев:
- нажатие «+» до 10 → кнопка блокируется, сообщение появляется;
- нажатие «−» до −10 → аналогично;
- возврат к 0 → красный фон.

## Выявленные проблемы и решения
1. Нет сброса — добавить кнопку Reset.
2. Нет сохранения состояния — использовать localStorage.
3. Нет адаптива — добавить media-запросы.
