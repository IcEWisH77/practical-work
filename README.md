# Практическая работа: Кейс-задачи

Данный репозиторий содержит решения 5 кейс-задач по практической работе. Все задачи выполнены в соответствии с требованиями.

## 📋 Список задач

### 2.1. Задача № 1. Стилистическое преобразование чисел (Python)
Программа запрашивает дату рождения (день, месяц, год) и выводит:
- День недели, соответствующий дате.
- Является ли год високосным.
- Текущий возраст пользователя.
- Дату рождения в формате `дд мм гггг`, нарисованную звёздочками (`*`), как на электронном табло.

**Как запустить:** `cd task1_date_stars` -> `python main.py`


### 2.2. Задача № 2. Счётчик (HTML/CSS/JS)
Веб-приложение с двумя кнопками («плюс», «минус») и окном результата.
Реализовано:
- Изменение значения на ±1.
- Смена фона результата: жёлтый (плюс), зелёный (минус), красный (ноль).
- Блокировка кнопок при достижении значений 10 и -10.
- Вывод сообщения «Вы достигли экстремального значения».

**Как запустить:** открыть `task2_counter/index.html` в браузере.


### 2.3. Задача № 3. Django-приложение «Приветствие» (Python/Django)
Веб-приложение на фреймворке Django, которое:
- Принимает имя пользователя через форму.
- Сохраняет имя в базу данных.
- Выводит персонализированное приветствие.
- Обрабатывает ошибку пустого поля ввода.
- Защищено от CSRF-атак.

**Как запустить:** 
```bash
cd task3_django_greeting
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
Затем открыть http://127.0.0.1:8000/.


### 2.4. Задача № 4. Интерактивный калькулятор (HTML/CSS/JS)
Веб-приложение с двумя инпутами и четырьмя кнопками математических операций.
Реализовано:
- Операции: сумма, разность, произведение, деление.
- Вывод результата.
- Обработка ошибок (ввод не-чисел, деление на ноль).

**Как запустить:** открыть `task4_calculator/index.html` в браузере.


### 2.5. Задача № 5. Аналитический обзор
Аналитический обзор проделанной работы по кейс-задаче № 2 (Счётчик). Разобраны критерии: функциональность, производительность, юзабилити, безопасность, масштабируемость, сопровождаемость, переносимость, качество кода и тестирование.

**Файл:** `task5_review/review.md`
